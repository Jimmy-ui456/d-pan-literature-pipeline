# 限制

- 检索由数据源、查询词、分页预算和服务端可用性共同限制；结果不是系统综述的穷尽检索。服务限流、失败或截断会写入审计，不能据此推断不存在相关文献。
- 元数据快照会过期。离线导入默认不会重新联网，因此撤稿、勘误、更新或跨库冲突在未重新核验时仍可能未知；明确使用在线核验后也只反映当时可取得的来源。
- PDF 获取和文本提取依赖可访问链接、页数/大小限制和启发式 Results 定位。链接、下载成功或同名文件都不等于 PDF 与记录身份匹配；未可靠定位的内容不能当作结果证据。
- 自动规则会分类、排序和从文字中提取候选数字，但数字与策略或产品出现在同一句不等于产量归属，也不构成实验结论。
- 人工审核是记录可追溯的纳入决定，不是自动或替代性的科学结论。审核者仍须阅读原始证据、判断研究设计和适用范围。
